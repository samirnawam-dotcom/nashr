Nashr - MENA media-buying marketplace demo (V30)
================================================
Source: https://claude.ai/artifact/RdF8uohoEAyJJyxSwRnXjh

How to open
  Double-click index.html. It is one self-contained file: no build step,
  no server, no dependencies.

Notes
  - Fonts load from Google Fonts, so the first load needs an internet
    connection. Offline, the page falls back to system fonts.
  - All demo data is seeded in the browser and stored in localStorage.
    Use the Demo guide to reset or fast-forward the demo clock.
  - Outside claude.ai, file downloads (CSV/receipts) use a normal browser
    download. The "Try Athena AI" button needs the claude.ai runtime and
    is unavailable when the file is opened locally; Athena's built-in
    planning still works.
